# jenkins-pipeline-demo

TP d'initiation à Jenkins (projet académique).

Pipeline déclaratif à trois étapes : Build, Test et Deploy. Les étapes affichent actuellement un simple message ; elles servent de squelette pour y brancher de vraies commandes (par exemple `mvn test`).
